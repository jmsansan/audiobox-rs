A practical guide to audiobox 0.1.0. Start with an audio buffer, compose the operations you need, and write the result.

Quick start

Add the crate to your project. Rust 1.85 or newer is required.

Terminal
cargo add audiobox

Or add audiobox = "0.1" under [dependencies] in Cargo.toml. There are no optional dependencies or features to configure.

This complete program reads a WAV, trims it, normalizes its peak and writes FLAC:

main.rs
use audiobox::{EncodeOptions, NormalizeOptions,
    read_audio_file, write_audio_file};

fn main() -> audiobox::Result<()> {
    let original = read_audio_file("recording.wav")?;
    let ready = original
        .cut(0.0, 10.0)?
        .to_mono()
        .normalize(NormalizeOptions::default())?;

    write_audio_file("ready.flac", &ready,
        &EncodeOptions::default())?;
    Ok(())
}

Try the same operations on demo audio or your own clip in the browser sandbox.

The audio model

Audio stores planar f32 samples: one Vec<f32> per channel. A frame is one sample from each channel at the same time. All channels must have equal lengths, the sample rate must be valid, and samples must be finite.

Samples conventionally range from −1.0 to 1.0, but intermediate processing may exceed that range. Integer encoding clips to the output format's range. Use gain, normalization or a limiter to control levels before exporting.

Construct and inspect
use audiobox::Audio;

fn main() -> audiobox::Result<()> {
    let audio = Audio::new(vec![vec![0.0; 48_000]], 48_000)?;
    assert_eq!(audio.channels(), 1);
    assert_eq!(audio.frames(), 48_000);
    assert_eq!(audio.duration(), 1.0);

    let channel: &[f32] = audio.channel_data(0)?;
    let interleaved: Vec<f32> = audio.to_interleaved();
    let restored = Audio::from_interleaved(&interleaved, 1, 48_000)?;
    assert_eq!(channel.len(), restored.frames());
    Ok(())
}

Transforms return a new Audio; the original remains available. Getters such as all_channels() and channel_data() expose immutable slices.

Decode & encode

Use decode(&bytes) for automatic container detection. sniff(&bytes) returns an Option<AudioFormat> without decoding the samples. File helpers wrap the same codecs with filesystem I/O.

Bytes in, bytes out
use audiobox::{Audio, AudioFormat, EncodeOptions, SampleFormat,
    decode, encode, encode_with_options, sniff};

fn main() -> audiobox::Result<()> {
    let audio = Audio::new(vec![vec![0.0; 4_800]], 48_000)?;
    let wav = encode(&audio, AudioFormat::Wav)?;
    assert_eq!(sniff(&wav), Some(AudioFormat::Wav));
    let restored = decode(&wav)?;

    let flac = encode_with_options(&restored, AudioFormat::Flac,
        &EncodeOptions {
            sample_format: SampleFormat::S24,
            compression_level: 5,
            ..EncodeOptions::default()
        })?;
    assert!(!flac.is_empty());
    Ok(())
}

Editing & channels

Time arguments accept seconds as f64 or an explicit TimePosition. Negative positions count from the end. Positions are rounded to the nearest frame and clamped to the buffer.

Exact frames or seconds
use audiobox::{Audio, TimePosition};

fn main() -> audiobox::Result<()> {
    let audio = Audio::silence(3.0, 2, 48_000)?;
    let first_second = audio.cut(
        TimePosition::Frames(0),
        TimePosition::Frames(48_000),
    )?;
    let last_second = audio.cut(-1.0, audio.duration())?;
    let joined = first_second.concat(&last_second)?;
    let reversed = joined.reverse().to_mono();
    assert_eq!(reversed.channels(), 1);
    Ok(())
}

Signal processing

Gain and filters work on floating-point samples. Resampling uses a windowed sinc filter. Fades support linear, equal-power and exponential curves.

A small processing chain
use audiobox::{Audio, FadeCurve, FilterOptions, FilterType,
    LimiterOptions, NormalizeOptions, NormalizeUnit};

fn main() -> audiobox::Result<()> {
    let audio = Audio::silence(2.0, 2, 44_100)?;
    let processed = audio
        .remove_dc_offset()
        .filter(FilterOptions::new(FilterType::Highpass, 80.0))?
        .gain_db(-3.0)?
        .fade(0.1, 0.3, FadeCurve::EqualPower)?
        .resample(48_000)?;

    let normalized = processed.normalize(NormalizeOptions {
        to: -16.0,
        unit: NormalizeUnit::Lufs,
        peak_ceiling_db: -1.0,
    })?;
    let limited = normalized.limit(LimiterOptions::default())?;
    assert_eq!(limited.sample_rate(), 48_000);
    Ok(())
}
MethodBehavior
gain(linear) / gain_db(db)Apply linear or decibel gain.
normalize(options)Normalize peak, true peak or integrated loudness. The default is peak −1 dBFS.
normalize_with_report(options)Return the normalized audio and a report of measured level, gain and ceiling restriction.
filter(options)Low-pass, high-pass, band-pass, notch, peaking, shelving or all-pass biquad.
limit(options)Lookahead limiter with configurable ceiling and release.
remove_dc_offset()Remove each channel's DC component.
detect_silence(options)Return silent frame ranges.
trim_silence(options)Trim silence at the edges.
speed(factor)Change playback speed and pitch together.
tempo(factor)Change duration with WSOLA time stretching.
pitch(semitones)Shift pitch while preserving duration approximately.

Filters require a positive frequency below Nyquist (half the sample rate). Stereo panning and channel edits have their own shape checks. Invalid arguments return an error.

Analysis

Inspect peak, RMS, an oversampled true-peak estimate, integrated loudness, waveforms and frequency content. Level methods return decibels; silent audio may return negative infinity.

Waveform and spectrum
use audiobox::{Audio, analyze};

fn main() -> audiobox::Result<()> {
    let audio = Audio::silence(1.0, 1, 48_000)?;
    let waveform = audio.waveform(256)?;
    let spectrum = analyze::spectrum(audio.channel_data(0)?,
        audio.sample_rate(), 2048)?;
    let loudness = audio.loudness();

    println!("Peak: {} dBFS", audio.peak_db());
    println!("RMS: {} dBFS", audio.rms_db());
    println!("Integrated: {} LUFS", loudness.integrated);
    println!("Buckets: {}, bins: {}",
        waveform.min.len(), spectrum.frequencies.len());
    Ok(())
}

waveform(buckets) returns min/max envelopes across channels. analyze::spectrum and analyze::spectrogram use an FFT size that must be a supported power of two. A spectrogram also takes a positive hop size in frames.

Integrated loudness uses K-weighting and gating. The range field is a legacy 400 ms block percentile estimate, not certified EBU R128 loudness range. The true-peak method is also an estimate.

PCM streaming

The stream module operates on raw PCM chunks. It is not a streaming parser for WAV, FLAC or MP3 containers. The decoder buffers incomplete frames; the resampler retains its filter history across chunks.

Decode and resample incrementally
use audiobox::{Endian, Limits, SampleFormat};
use audiobox::stream::{PcmDecoder, Resampler};

fn main() -> audiobox::Result<()> {
    let mut decoder = PcmDecoder::new(SampleFormat::S16,
        Endian::Little, 2, 48_000, Limits::default())?;
    let mut resampler = Resampler::new(48_000, 16_000,
        2, Limits::default())?;
    let pcm = vec![0_u8; 48_000 * 2 * 2];

    for chunk in pcm.chunks(1023) {
        let decoded = decoder.push(chunk)?;
        let output = resampler.push(&decoded)?;
        println!("{} output frames", output.frames());
    }
    decoder.finish()?;          // Reject an incomplete final frame.
    let tail = resampler.finish()?; // Drain the final filter tail.
    println!("{} final frames", tail.frames());
    Ok(())
}

PcmEncoder::new(format, endian) converts an Audio chunk to bytes via push(&audio). The sample rate and channel count must remain consistent within a stream.

Errors & limits

Fallible operations return audiobox::Result<T>. Match the stable ErrorCode to make decisions; the human-readable message supplies context.

Bound an untrusted decode
use audiobox::{DecodeOptions, ErrorCode, Limits,
    decode_with_options};

fn main() {
    let options = DecodeOptions {
        limits: Limits {
            max_duration_seconds: 60.0,
            max_channels: 2,
            max_decoded_bytes: 32 * 1024 * 1024,
            ..Limits::default()
        },
        ..DecodeOptions::default()
    };

    match decode_with_options(b"not an audio file", &options) {
        Ok(audio) => println!("{} frames", audio.frames()),
        Err(error) => match error.code {
            ErrorCode::LimitExceeded => eprintln!("Choose a smaller clip"),
            _ => eprintln!("Could not decode: {error}"),
        },
    }
}

Default limits allow up to 512 MiB of decoded PCM, six hours, 64 channels and sample rates between 1 kHz and 768 kHz. These are allocation safeguards, not a guarantee that every codec supports every rate or channel count. Set stricter limits for your application.

ErrorCode is non-exhaustive. Include a fallback arm when matching it.

Release limitations

Version 0.1.0 is the first independent Rust release. Its API and capabilities do not exactly match the TypeScript package.

  • MP3 encoding uses a basic CBR, long-block model. There is no VBR encoder, psychoacoustic tuning, transient block switching or encoder bit reservoir.
  • FLAC level 0 uses verbatim frames; levels 1–8 currently share the same fixed-predictor search.
  • There is no PCM dithering, Sony Wave64, RF64/BW64 writing, or full container streaming.
  • Metadata writing is supported only where implemented. CAF and MP3 metadata writes are not available.
  • Loudness range and true peak are estimates; see the analysis notes.
  • The crate is synchronous. Filesystem helpers need a native filesystem; the browser sandbox uses byte buffers instead.

The sandbox runs a WebAssembly build of the Rust crate, with a small separate bridge and stricter limits for browser memory. It demonstrates selected operations, not an arbitrary Rust compiler. Read the source or open an issue for a missing capability.
